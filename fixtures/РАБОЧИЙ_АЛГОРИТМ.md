## ШАГ 0 — Уточнить пульт

**Всегда первым вопросом:** «На какой пульт нужен шаблон?»

Известные пульты и их форматы:
| Пульт | Формат шаблона |
|---|---|
| ETC EOS / Ion / Apex | GDTF (.gdtf) или встроенная библиотека |
| grandMA2 | XML (.xml в RAR/ZIP) |
| grandMA3 | GDTF (.gdtf) или MA3 XML |

## АЛГОРИТМ ДЛЯ ETC EOS

### 1. Проверить встроенную библиотеку EOS
→ https://fixture-library-hub.etcconnect.com/  
- Платформа: **Eos v3**
- Фильтр по производителю → фильтр по продукту
- Если есть: **готово**, записать версию (Revision) и режимы
- Robe в библиотеке называются «Robin [название]»

### 2. Проверить GDTF Share
→ https://gdtf-share.com (требует логин пользователя)  
- Производитель → Fixtures → скачать кнопкой "Download File"
- Брать **последнюю по дате** версию от производителя (иконка "Uploaded by manufacturer")
- Robe Lighting — искать под «Robe Lighting» (не просто «Robe»)
- T.5 Profile у Robe называется «Robin Tdot5 Profile»

### 3. Если нет нигде — создать GDTF вручную
- Найти официальный DMX PDF мануал производителя
- Написать Python скрипт генерации GDTF (по образцу CKC Tourist M9)
- Сохранить в `/Users/ts/Claude/Projects/EOS ШАБЛОНЫ/GDTF/`
- Подать запрос в ETC Fixture Library Hub (кнопка "Create request")

## АЛГОРИТМ ДЛЯ grandMA2

### 1. Проверить официальный сайт производителя
- Robe: robe.cz → Downloads → Lighting Consoles (JS-рендер, нужен Chrome MCP)
- Light Sky: lightsky.com.cn → Downloads
- Другие: гуглить «[производитель] grandma2 fixture download»

### 2. Проверить MA Share
→ https://fixtureshare.malighting.com  
- Поиск по названию прибора

### 3. Если нет нигде — сгенерировать XML из DMX PDF
- Скачать официальный DMX мануал (PDF)
- Написать Python скрипт генерации MA2 XML (по образцу Super Scope)
- Структура: `<MA> → <FixtureType> → <Modules> → <Module> → <ChannelType>`
- DMX значения: 8-bit v → `v * 65536` (24-bit строка), max = "16777215"
- Сохранить в `/Users/ts/Claude/Projects/EOS ШАБЛОНЫ/MA2_Profiles/[Производитель]/`

## ПРАВИЛА ПОИСКА И СКАЧИВАНИЯ

1. **Сначала спрашиваем пульт — потом ищем** (не тратить время на неверный формат)
2. **Встроенная библиотека пульта** > GDTF Share > ручная генерация
3. **Брать только официальные файлы** (от производителя, не community)
4. **Новые приборы** (< 6 месяцев) часто отсутствуют — сразу к GDTF/генерации
5. **Дубли при скачивании** — скачивать один раз, один клик на Download File
6. При скачивании через браузер — файлы идут в ~/Downloads пользователя
