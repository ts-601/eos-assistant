# EOS Agent Sandbox

Среда самообучения агента. Здесь агент хранит всё что узнал.

```
sandbox_env/
├── README.md          ← этот файл
├── learned/           ← автоматически записанные решения (из тега <learn>)
├── corrections/       ← исправления пользователя ("нет, нужно вот так")
└── stats.json         ← статистика: сколько команд, ошибок, исправлений
```

## Как работает самообучение

1. Агент решает задачу → если решение нетривиальное — добавляет тег `<learn>`
2. `agent.py` парсит тег → автосохраняет в `learned/`
3. При следующем запросе `indexer.py` находит похожую ситуацию → агент видит готовое решение
4. Пользователь поправил агента → сохраняется в `corrections/`

## Цикл улучшения

```
Запрос → Поиск в learned/ + corrections/ → Ответ → Новое решение → learned/
```
